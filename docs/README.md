# DeepRubric Project Page

Static project page for the DeepRubric paper.

## Preview

Open `index.html` directly in a browser, or serve the directory:

```bash
python -m http.server 8123
```

Then visit:

```text
http://127.0.0.1:8123/
```

## Deploy

This directory is GitHub Pages ready. Push the contents of `DeepRubric-page/` to a GitHub Pages branch or repository root.

If a compiled paper PDF is available, place it in this directory as `paper.pdf` and update the Paper button in `index.html`.
