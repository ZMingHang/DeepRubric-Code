DeepRubric: Evidence-Tree Rubric Supervision for Efficient Reinforcement Learning of Deep Research Agents

Minghang Zhu, Chuyang Wei, Junhao Xu, Yilin Cheng, Zhumin Chen, Jiyan He

Build the research task and its rubric from the same retrieved evidence tree, then train a tool-using deep research agent with grounded supervision.

Paper Code README Assets

Abstract

Deep research agents synthesize long-form reports by searching and reasoning over retrieved evidence. Rubric-based reinforcement learning can improve these agents, but query-conditioned rubrics often miss latent information needs. DeepRubric reverses this direction: it first builds evidence trees from local corpora, then co-synthesizes aligned research queries and grounded rubric criteria from those trees. The resulting supervision is verified, converted to training data, and used for GRPO training with local search, browse, and scholar tools.

Overview

1 Retrieve

Collect Wikipedia and OpenScholar evidence with local retrievers.

2 Build trees

Expand seed topics into evidence trees with selected leaves.

3 Synthesize

Generate research queries and factual/logical rubric criteria.

4 Train

Run GRPO with search, browse, scholar, citation, and rubric rewards.

Method

Evidence-first construction

DeepRubric samples seed topics, recursively decomposes them into sub-queries, and grounds each node in retrieved evidence before any query-rubric pair is generated.

Rubric co-generation

Selected evidence leaves are merged into a coherent research query while producing atomic factual and logical criteria that remain tied to source evidence.

Closed-loop training

The same retriever endpoints used during data construction are exposed to the training agent through search, browse, and scholar tools.

Reproduce

The release contains scripts for deploying retrievers, constructing data, converting verified examples, and starting GRPO training. Large corpora, indexes, generated datasets, checkpoints, logs, and private service configs are intentionally excluded. 

START_RETRIEVERS=1 bash scripts/run_pipeline.sh
