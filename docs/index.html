DeepRubric: Evidence-Tree Rubric Supervision for Efficient Reinforcement Learning of Deep Research Agents

An evidence-first data construction and RL framework that builds query-rubric supervision from retrieved documents before training deep research agents.

Minghang Zhu, Chuyang Wei, Junhao Xu, Yilin Cheng, Zhumin Chen, Jiyan He

Paper Code README Assets
9,064 retained query-rubric pairs
140 GRPO update steps
750 RL GPU-hours
68.3 average over SQAv2, ResearchQA, DRB

Abstract

Generate the task and the reward from the same evidence structure.

Deep research agents synthesize long-form reports by searching and reasoning over retrieved evidence. Rubric-based reinforcement learning can improve these agents, but query-conditioned rubrics often miss latent information needs. DeepRubric reverses this direction: it first builds evidence trees from local corpora, then co-synthesizes aligned research queries and grounded rubric criteria from those trees. The resulting supervision is verified, converted to training data, and used for GRPO training with local search, browse, and scholar tools.

Highlights

What changes compared with query-first rubric generation?

01

Evidence-first task construction

Sample seed topics, recursively decompose them into sub-queries, and ground each node in retrieved Wikipedia or OpenScholar evidence.

02

Bottom-up query-rubric synthesis

Selected evidence leaves are merged into a coherent research query while producing atomic factual and logical rubric criteria.

03

Verifier-constrained revision

A separate audit step returns KEEP, REVISE, or DROP while requiring revised factual criteria to stay grounded in selected tree leaves.

04

Local-tool RL loop

Training rollouts use local search, browse, and scholar tools backed by the same corpora used to build the supervision.

Reproduction

From retriever deployment to training startup.

1

Download assets

Fetch ASearcher local Wikipedia knowledge and OpenScholar datastore, then set virtual paths such as WIKI_RETRIEVER_ROOT.

2

Deploy retrievers

Run local Wikipedia and OpenScholar retrieval endpoints for search, browse, and scholar.

3

Construct and verify data

Build evidence trees, run KEEP/REVISE/DROP verification, and export verified query-rubric JSONL.

4

Train

Convert JSONL to verl-tool parquet and start GRPO training with the same retriever endpoints.

START_RETRIEVERS=1 bash scripts/run_pipeline.sh

The code release keeps large corpora, indexes, generated datasets, checkpoints, and private configs out of the repository. Paths in the scripts are intentionally written as /path/to/... placeholders.
